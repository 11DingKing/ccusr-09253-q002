# 实训学时合规与冻结服务

该服务汇聚学员签到、导师确认和请假修正事件，按培养方案与时区重放学时状态，并保存可追溯的学期冻结快照。项目还提供导师分配、证明材料、豁免复核、规则版本、名额、通知和数据留存等领域模块，供后续业务扩展时复用统一的状态与审计约束。

## 运行方式

默认数据保存在项目目录的 SQLite 文件中。安装依赖后执行 `uvicorn app.main:app --host 127.0.0.1 --port 8000`，健康检查地址为 `/health`，业务接口位于 `/api`。

## 批量导入的幂等语义

`POST /api/plans/{plan_version}/events` 按事件编号（event_id）结合内容指纹（类型、学员、负载的 SHA-256）判定幂等：

- **完全相同的重放**：返回 201，事件列入 `duplicates`，状态不变（幂等成功）。
- **负载校验失败**：仅该事件列入 `rejected` 并附原因，同批其余合法事件正常导入。
- **同号但内容不同**（例如源系统"更正"后复用编号）：整批原子拒绝，返回 409 与脱敏后的冲突详情（事件编号、不一致字段名、双方内容指纹），不留下半批数据。冲突全量详情（含请求方负载）在回滚后单独事务写入 `import_conflicts` 审计表，可凭响应中的 `batch_id` 对账；业务 API 不返回已存储事件的学员标识或负载，避免泄露无权限学员信息。

导入在单一事务内提交，进度查询与冻结快照永远读不到未提交或已回滚的事件；并发重试由数据库唯一约束与"先插入、后判定"的指纹比对保证恰好一次生效。
